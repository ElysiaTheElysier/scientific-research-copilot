# Scientific Research Copilot

An evidence-grounded AI assistant designed for scientific research papers. The system ingests research PDFs, performs layout-aware parsing and context-grounded multimodal figure understanding, and structures documents for high-precision Retrieval-Augmented Generation (RAG).

---

## Features

- **Single-Pass PDF Parsing**: Uses [Docling](https://github.com/DS4SD/docling) to extract structured Markdown and embedded figures in one efficient pass.
- **Context-Grounded Academic Figure Understanding**: Enriches charts, architecture diagrams, and plots with deep academic descriptions generated by high-capacity vision models (e.g. Ollama `llava:13b`). The model receives full paper context:
  - Paper title and abstract
  - Section headers
  - Original author figure captions
  - In-text discussion paragraphs citing each figure (`Figure X`)
- **Multimodal Section & Figure Chunking**:
  - Automatically enriches section texts by replacing raw `<!-- image -->` placeholders with structured figure analysis blocks.
  - Generates dedicated multimodal figure chunks containing the image file path, caption, and VLM analysis for direct figure search.
  - Short sections (<= 1000 words) remain intact to preserve full context; long sections are split with character-level overlap; noise sections (e.g., `References`) are filtered out.
- **Unified Modular Pipeline**: Easily run individual stages or the entire pipeline via CLI or import as reusable Python modules.

├── data/

## Quickstart

### 1. Installation

Using `uv` or `pip`:

```bash
uv sync
# or
pip install -e .
```

Ensure Ollama is running and has the vision model installed:

```bash
ollama pull llava:13b
ollama serve
```

### 2. Running the Ingestion Pipeline

Run the entire pipeline end-to-end (uses `llava:13b` by default):

```bash
python -m src.ingestion.pipeline --all
```

Or execute specific stages individually:

```bash
# Stage 1: Convert PDFs and extract figures
python -m src.ingestion.pipeline --stage convert

# Stage 2: Context-aware figure captioning using Ollama llava:13b
python -m src.ingestion.pipeline --stage caption --vlm-model llava:13b

# Stage 3: Section-aware and multimodal figure chunking
python -m src.ingestion.pipeline --stage chunk
```

### 3. Running Scripts Standalone

Each module features a standalone CLI:

```bash
# Convert PDFs
python -m src.ingestion.convert --raw-dir data/raw --output-dir data/processed

# Caption figures with academic context
python -m src.ingestion.caption --images-dir data/processed/images --processed-dir data/processed --model llava:13b

# Chunk documents with multimodal figure enrichment
python -m src.ingestion.chunk --processed-dir data/processed --image-descriptions data/processed/image_descriptions.json --output data/processed/chunks.json
```

### 4. Vector Database Indexing & Search

Index all chunks into Qdrant using Qwen3-Embedding-0.6B on GPU:

```bash
python -m src.retrieval.vectordb
```

Search vector database directly:

```bash
python -m src.retrieval.vectordb search "system architecture"
```

### 5. Running the Scientific RAG Copilot

Ask a single question:

```bash
python -m src.rag "What is post-graph-rag and what database does it use?"
```

Or enter interactive chat mode:

```bash
python -m src.rag
```

### 6. Running Tests

```bash
python test/test_chunking.py
```
